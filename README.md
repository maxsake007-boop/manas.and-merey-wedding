# Свадебное приглашение — Манас и Мерей 💍

Интерактивное электронное свадебное приглашение на 22 октября.

## Возможности
- 📸 Детские полароидные фото жениха и невесты с анимацией появления
- 🎶 Музыкальный плеер с любимой песней (положите трек в `public/music/wedding.mp3`)
- ⏳ Живой таймер обратного отсчета до начала торжества (22 октября, 18:00)
- 📅 Календарь на октябрь 2026 с сердечком на дате свадьбы и кнопкой «Добавить в календарь (.ics)»
- 📍 Локация банкета (**Tinchlik Plaza**, Навои) с кнопками для Яндекс Карт, 2ГИС, Google Maps и копированием адреса
- 💌 Форма подтверждения присутствия (RSVP) с сохранением и отправкой в Telegram / Google Таблицы

## Быстрый запуск

1. Установка зависимостей:
   ```bash
   npm install
   ```

2. Запуск локального сервера разработки:
   ```bash
   npm run dev
   ```
   Сайт откроется по адресу [http://localhost:3000](http://localhost:3000).

3. Сборка для публикации:
   ```bash
   npm run build
   ```

## Настройка музыки
Поместите ваш аудиофайл в папку `public/music/` с именем:
- `wedding.mp3` (или `music.mp3`)

## Настройка отправки RSVP (Telegram / Google Таблицы)
Скопируйте `.env.example` в `.env` и укажите данные вашего Telegram бота или Google Apps Script:
- `VITE_TELEGRAM_BOT_TOKEN`
- `VITE_TELEGRAM_CHAT_ID`
- `VITE_GOOGLE_SHEETS_URL`
